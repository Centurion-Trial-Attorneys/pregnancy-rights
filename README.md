# pregnancyrights.law

Pregnancy, leave, lactation, and working-mother rights resources and intake site for California workers, operated by Centurion Trial Attorneys, APC.

- Source in `src/`, built site in `public/`. Run `python3 build.py` (needs `pip install markdown`).
- Netlify publishes `public/` when `main` changes.
- Intake link and provider, phone, team, case results, other sites, and nav: `src/site.json`. FAQ: `src/faq.json`. Pages: `src/pages/`. Articles: `src/articles/`.
- Photos: Unsplash, hotlinked with credit (homepage hero and article photos). Attorney portraits are self-hosted.
- The Archivo font (Omnibus-Type) is self-hosted under the SIL Open Font License 1.1.
